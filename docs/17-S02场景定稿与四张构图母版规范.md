## 5. 核验与使用限制

```bash
python scripts/check_character_lock.py
```

此脚本检查当前人物锁和BM01批准四视图、不恢复JK03；它不是新成品视觉识别器，也不自动核定场景和所有构图hash。每次使用构图仍须按current组合清单核对文件、记录实际输入并人工看结果。

本轮F05/F06已文件／逐图视觉检查：PNG尺寸正确、完整头手与相应取景、保持人物服装方向、无椰子吸管、网格只在地面。F05尾饰靠近边缘，F06保留上下留白；纹理／脸部局部仍有生成差异，不宣称像素复刻、生物身份认证或动态衣物连续性。

F01／F02 保留既有已查看状态。BM01 四视图已批准，F05／F06 保留已视觉检查、等待逐图确认的状态。动态举手、横移和脚步的出框情况按成片逐段核对。

正式资产目录和真实清单仍在本地忽略区；用户明确要求README人物图后，仅按[8张图例清单](images/characters/manifest.json)发布字节一致展示副本，包括本篇F01/F02/F05/F06。根README直接嵌图并保留逐图批准标签，原始参考照片、其他人像／候选及私有生产记录不上传。图片展示不创建前端／画廊，也不升级动作或用户批准状态。
