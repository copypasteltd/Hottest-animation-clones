## 3. 参考输入分工

- Image 1：对应人物已锁定v1正面锚点，定义同一人物、脸、发型、体型、服装与媒介。
- Image 2：已选S02空场，定义白背景与浅灰网格地面。
- 四张分别从同一人物主锚点＋同一场景锚点生成，不以新全身图递归生近景，避免多代漂移。
- SA02保持2D动画线稿/赛璐璐，不因为网格空间而真人化/3D化；JK03保持写实，不动漫化，不换制服或浓妆。

人物v1原始白底文件继续保留、hash不变。新图是`character@1 + scene@1 + framing@1`组合视图，不是重写人物身份锚点。

源视频/源骨架仍独立，角色场景组合通过不替代源动作/时序验收。JK03的148cm仍是设计参数，不能用生成网格测出真实厘米身高。

## 5. 检查与后续使用

每张需检查：PNG可解码/实际尺寸、对应角色/媒介与服装、头顶/双手/裙摆和取景边界、全身鞋底、S02地格/无墙格、无额外人物/物品/文字。轻微生成差异按实际记录；关键脸、服装、构图不符不能仅凭API success通过。

人物输入检查命令仍为：

```bash
python scripts/check_character_lock.py
```

该检查不覆盖新场景和四图成品。场景/组合输入的固定hash与实际结果/视觉记录另存本地清单，未自动加入模型执行器。新成品若作为后续默认参考，使用其具体组合ID/版本与hash，不用“最新图”模糊引用。

人读任务说明/提示词/画廊在docs/runs下，成品在output/imagegen下，正式场景/构图媒体和机器清单在standard-assets下；均遵循项目本地资产默认忽略。公开源码可维护本篇文字规则，不分发人物、第三方图或真实运行清单；本轮不暂存、不提交、不推送。
