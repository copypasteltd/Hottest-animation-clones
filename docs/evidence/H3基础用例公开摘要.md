# H3参考动作迁移：公开证据摘要

日期：2026-11-13。此页是本项目本地试验记录的脱敏文字摘要，不附第三方媒体、角色图、远程日志、设备配置或上游节点源码。公开仓库使用者不能仅凭此摘要独立复现或审查原始素材。

## 已记录的试验事实

- 一张人物与室内场景图，加一段约13秒的单人舞蹈视频作为参考输入。
- 既有ComfyUI H3参考视频工作流完成两遍采样，执行历史记为success。
- 输出832×1312、24fps、313帧，视频流约13.04秒。
- 生成墙钟约1625秒；这是特定配置的一例，不代表通用速度、成本或批量吞吐。
- 交付版复制原音频，音频压缩数据校验一致；这不证明动作与音乐逐拍准确。

## 抽样观察及限制

人物服装和目标房间在抽样中基本保留，主要动作类别可辨；部分手型、抬手拍点与源动作不同，后段脚部出框，场景透视也不是像素不变。未做完整逐帧手指标注、身份识别或质量量化，因此不称为精确动捕通过。

另一次对当时部署的H3参考节点实现进行只读检查，确认该试验路径未显式调用身体/手部骨架提取器，而是将RGB参考编码为多模态条件和视频VAE潜变量。不能将该潜变量当作结构化关节轨迹。

## 可以支持与不能支持的结论

支持：RGB参考迁移可作为视觉分支的候选；源骨架提取需要独立实现；视觉生成成功与动作保真应分别验收。

不支持：标准角色/白模场景已完成、骨架库已建成、所有模型均支持骨架输入、任意角色均能准确复现，或统一白模路线已经优于原片直接参考。
