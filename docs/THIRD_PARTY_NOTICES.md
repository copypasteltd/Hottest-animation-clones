# 第三方材料与数据许可边界

本项目根许可证MIT适用于本仓库原创代码、需求说明、维护脚本和虚构示例；不授予任何第三方素材、软件或模型本来没有的权利。

## 默认不分发

- 用户下载/上传的舞蹈视频、人像/角色图、音乐和音轨。
- 生成结果、真实骨架数组、真实标注/来源数据，除非另获授权并明确许可。
- 模型权重、人体参数模型、上游节点源码和第三方ComfyUI工作流。
- 远程控制技能、设备配置、运行日志和访问凭据。

这些文件在本地可按授权使用，但默认被Git忽略，不进入初始提交或代码许可证覆盖范围。把原片变成标准白模或提取轨迹不自动清除其原有条件。

## 依赖

开发校验使用jsonschema，构建使用setuptools，具体版本约束见包元数据；第三方依赖由其各自许可证管理。本仓库不vendor这些库。CI引用外部Actions，其服务与许可条件独立。

H3/ComfyUI等仅作为已发生本地试验或未来可替换适配方向的文字说明；仓库不内置其权重/源码，不宣称它们采用MIT或具有通用商业授权。

## 将来新增第三方文件时

必须记录来源URL、版本/commit、原许可证、修改范围、归属与所需通知，并在公开前检查用途/再分发限制。不能因GitHub显示开源、下载免费或网页公开就直接再许可。纯链接和脱敏自述摘要也不构成数据开放证明。
