# 安全与隐私说明

当前仓库包含需求、Schema、虚构示例和维护基础代码，不提供在线服务或已部署模型。文档/索引保护检查只减少误提交，不是通用沙箱或完整安全审计。

## 报告问题

- 普通可复现缺陷可用Bug Issue模板，但不要粘贴token、账号、用户路径、设备地址或真实媒体。
- 涉及凭据/私有媒体泄露时不要开公开Issue。指定GitHub仓库尚未配置独立私密联系地址；仅在平台Private vulnerability reporting已启用时使用，否则先向维护者询问私密渠道，不编造邮箱、不公开敏感内容。
- 若仓库历史中出现凭据，应先撤销/轮换，再按维护者明确计划处理历史；删除最新文件不能解除泄露。

## 配置与运行边界

- 仓库仅提供环境变量名称，不提供远程服务端点、密钥或用户账号。
- 真实机器配置留在忽略的本地文件，敏感值优先由环境注入；导出包和日志必须脱敏。
- 模型输入、文件、NPZ、工作流和第三方输出均不可信；NPZ不启用pickle，不执行数据字段中的命令。
- 本地读写限定项目根并解析指外链接；远程任务需具体授权、队列所有权和防重复提交。
- CI使用只读仓库权限，不访问GPU、远程设备、模型账户、真实素材或发布凭据。
