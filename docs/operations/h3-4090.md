# 4090 ComfyUI 接线与执行

使用指定 RTX 4090 的 ComfyUI。工作流目录相对于该设备的 ComfyUI 根为 `user/default/workflows/社区精选H3_人物与场景替换_实验`。实际设备路径及运行配置由项目私有说明和配置保存。公开配置样例供核对字段。[配置示例](<../../configs/project.example.toml>) · [工作区](<../maintenance/workspace.md>)

## 接线检查

| 检查 | 登记内容 |
| --- | --- |
| 工作流身份 | 目录内实际 JSON 相对路径、SHA256、活动分支、可提交的 API 执行图及其与原图的版本关系。 |
| 可执行条件 | 活动分支所需节点和模型、实际支持的媒体格式、时长、帧数、帧率、画幅与输出节点。 |
| 运动参考 | 源视频输入位、原片及必要派生文件的身份、实际截取或重采样参数。 |
| 人物与场景 | 目标图输入位、S02 的提供方式、多人按顺序或稳定标识的逐人对应。 |
| 音轨 | 源音、生成音、混合或静音的实际处理路径。 |

单目标图输入可以试用含人物与 S02 的组合母版。独立场景图、多参考图和多人输入各自核对实际活动连接。在匹配授权样片上确认人物身份、场景、动作范围及输出质量。样片通过后，将该工作流版本与可执行组合纳入常规任务。一个工作流可以覆盖已经验证的多个组合。[路线验收](<../verification/acceptance.md>)

## 提交与找回

1. 源视频负责动作和节奏，目标图负责人物外观与构图。提交前保存尝试标识和实际输入清单，记录版本、文件哈希、输入位映射、时长与画幅。裁切、重采样或分段时保留实际范围与回到源时间的说明。
2. 依据已核验的可执行图提交一次，记下回执及对应任务。读取队列和历史时按同一任务标识查询，并保留当前尝试的结果。操作限于本次任务及其回执。
3. 断线、超时或回执不明时标 `unknown`，优先用提交记录、队列、历史及输出核对原尝试。查实未提交或已失败后，再按实际情况决定新尝试。可确认的结果沿原尝试继续恢复。
4. 按回执找回实际输出，以本地媒体检查及审核结果推进交付。保存输入、回执和审核之间的关系。[运行记录](<run-record.md>) · [成片验收](<../verification/acceptance.md#delivery-review>)

历史 H3 样片只覆盖当时的单人输入组合。当前路线需要对应活动分支和 S02 样片证据。[历史实验](<../evidence/H3基础用例公开摘要.md>) · [当前进度](<../product/status.md>)
