# 动作迁移视频库 · 前端开发与设计文档 v1.0

状态：**v1 已实现并通过本地验收；公开示例使用 GitHub Pages 手动发布**。目标是让访客一进站就能看到近期又有热度的动作迁移成片，并能在全库通过标题、说明、关键词和标签找到想要的动作。以 [DeepSeek Harness 自媒体工作台的「灵感」页](https://bozhufarm.com/dsh/)为视觉基准，不改变现行整片重画、双版本交付或画像数据契约。

## 1. 产品范围

| 场景 | v1 行为 |
| --- | --- |
| 看全库 | 默认「成片」视图，SA02 动漫和 BM01 真人共用一个按分数排序的列表，一份成片一张卡，不隐藏同源的不同成片。可「只看定稿」或切到「按作品」聚合。已纳入的历史定稿也可检索、分页、直达。两视图均先搜全库，再分页。 |
| 找某种动作 | 检索可展示的标题、简介、原始标签、清洗标签、中英别名、作者、媒体规格、取景、场景／音轨配置和验收状态；可选择同时搜观察、同刻对照和证据限制。结构化标签与说明命中分开，支持按来源、版本、横竖屏与取景筛选。 |
| 看成片 | 打开右侧详情／移动端全屏详情，查看已授权封面、播放或替代状态、版本、标签来源与适用范围。选择某个媒体后才加载播放器资源；不编辑、不重新生成。 |
| 维护目录 | 在本地维护数据，核验后产出只读静态目录快照。公开入口只包含逐项批准的记录；私有全库可用同一个静态前端在本机查看，但不进入公网构建。 |

不做登录、写入 API、数据库、SSR、实时爬取、实时全站播放计数、推荐模型、在线转码、上传后台或 DeepSeek Harness 插件集成。v1 的「模糊检索」指文本与标签，不是按画面、音色或音频相似度查重。「所有视频」以当前数据集和授权范围为边界；不能从公开页枚举私有记录。

## 2. 视觉设计：复用「灵感」页的视觉结构

参考插件作者公开的[浅色灵感页截图](https://bozhufarm.com/dsh/assets/f-home-light.webp)与[深色灵感页截图](https://bozhufarm.com/dsh/assets/f-home-dark.webp)：两者右侧示例是有序卡片墙，左侧是自由画布加助手。**本库默认复刻右侧卡片墙的视觉结构**：窄图标轨、左上圆角分段导航、居中留白与短文案、单行胶囊输入、胶片式缩略入口、首屏瀑布流、底部半透明控制条。右侧面板沿用参考的轻量容器感但用于成片详情。没有核实本机安装版本的当前视口，也没有测到其实际 CSS；以下尺寸与色值是实现起点，不能当作原版读数。进入开发后先对照目标版本实测校准；未取得目标版本截图时，视觉验收只能写「对齐公开参考」，不能写「与本机当前版本完全一致」。

| 参考部位 | 动作库对应部位 | 布局与样式要求 |
| --- | --- | --- |
| 左窄轨、左上分段导航 | 自有项目标识与「视频库／标签」入口；右上主题切换、数据更新时间入口 | 桌面轨宽起点 52 px。导航紧凑，选中项用中性高对比胶囊（浅色黑底、深色白底），只放能操作的功能，不移植原版商标、成稿、排期或假按钮。 |
| 居中标题区与输入框 | 「动作迁移库」简短说明、真实库内计数或更新时间；单行搜索 | 弱化辅助文字，主数字加深；文案带宽约 420–560 px，左对齐排版但整块居中。输入支持清除、移动键盘搜索和按 Enter 立即查询；不做大横幅、复杂渐变或仪表盘大数字。可用至多 8 个已授权小缩略做导航，不自动轮播。 |
| 流式媒体卡片 | 封面、标题、版本、时长、最多 3 个有用标签及溢出计数 | 封面层主导。时长与播放提示放在封面角，详情展开全部标签。竖屏/横屏维持相应比例，完整动作封面以等比留空为先，不裁掉鞋或手；无封面用中性比例占位，不随机抓原片图。元数据只弱化，不低于可读对比。 |
| 底部浮动工具条 | 作品／成片切换、快捷标签、排序、筛选计数 | 桌面居中浮动，底部留安全间距；窄屏仅保留关键模式、筛选和排序入口，标签选择在弹层。分页在卡片墙末尾独立呈现；滚动底部给工具条留出空间，不能遮住翻页按钮。 |
| 右侧助手容器 | 可关闭的只读详情 | 桌面右侧约 420–520 px，窄屏呈全屏对话面板；内容按播放器、版本、标题、标签、说明顺序。关闭回到同一页、同一滚动位置和触发焦点。不重做无限画布；随机摆放与排名、分页和键盘顺序冲突。 |

**主题令牌起点（待截图校准）**：浅色背景 #FAFAFA、卡面 #FFFFFF、主字 #18181A、次字 #59595F、分隔 #E8E8EA；深色背景 #171719、卡面 #252527、主字 #F3F3F5、次字 #B8B8C0、分隔 #39393D。浅深仅一套语义令牌切换；彩色来自真实封面和很小的状态点，不给整卡上主题渐变。系统无衬线字体（Windows 优先 Segoe UI／微软雅黑，macOS 系统字体／苹方），不从外网加载字体。桌面标题区 26–32 px，卡标题 14–16 px 半粗，辅助 12–13 px；圆角 12–16 px，卡内留白 8–12 px，列间距 14–18 px，浅边框和轻阴影。浮条有不支持背景模糊时的不透明降级。日期按界面时区显示，排序仍用 UTC 时间戳。

**响应式与布局顺序**：以内容宽度而非窗口宽度决定列数，默认阈值 1280／1040／760／360 px 对应 5／4／3／2 列，更窄为 1 列；详情打开后重算但不改变条件、页码或已有焦点。用实际封面比例先占位，瀑布流以「把下一张排在当前最短列，列高相同时取靠左列」布置；DOM 顺序始终是排序后顺序，不用 CSS 多栏或 dense 反向重排。迁移版未获播放许可时卡片保留，仅限该条目本身有元数据公开许可。目标首屏在 1440×900 显示完整搜索、排序入口和至少第一排卡片起始位置；390 px 宽能看到搜索与第一排封面，不横向滚动。

**视觉验收**：用固定测试目录、100% 缩放、相同内容区宽度核对 1440×900 与 1280×800 的浅深色；390×844 验证触屏适配。取得实际灵感页参考后，逐项比对轨道/顶部控件占位、标题与搜索区边线、卡片列数与列距、浮条位置、字体层级和表面明暗。尺寸中心与边线以采集后的目标值为准（结构尺寸偏差建议 ≤8 CSS px）；先屏蔽内容图片与文案区域再看结构差异，不能凭总像素相似度遮住错误。移动端及库特有控件属于有意适配。记录参考版本、宽度、主题和批准偏差；截图不随站点发布。

## 3. 浏览、详情与交互状态

- **卡片身份**：按平台作品和明确的媒体选择区分分 P／帖子内媒体；完全同一身份及源文件只在作品墙聚合一次。不同源媒体不可因标题或标签相同被合并。卡片默认展示符合当前筛选及发布范围的最新已取回版本（相同时间按稳定 ID）；「成片」模式和详情可找到每份在当前数据集内的历史版本。以稳定公开 ID 直达，不把仓库私有尝试路径转换成 URL。 公开 ID 由发布清单分配并持久保存，不从标题、排序位置或原片哈希计算；同一成片重新导出仍用原 ID。没有匹配成片时，仅在没有成片限定且该条元数据获准展示时保留作品卡。
- **分页**：每页默认 24 条。检索、结构筛选、排序后才切页，显示总条数、页码、上一页/下一页及首尾；切检索条件、排序或视图回到第一页。直接访问过大页码钳到最后一页；没有匹配时不显示假页码。搜索更新默认替换历史，翻页和打开详情使用可回退的历史状态。返回列表恢复查询、筛选、页码和滚动锚点。
- **详情**：同卡版本切换保留用户上下文，但停掉旧播放器、不默认续播。明确区分「原片标签」「成片观察」「成片配置」以及有证据的候选。确认观察的抽样限制可见，失败、待验收、缺媒体或未经许可不是播放成功。公开详情不挂私有证据图或回执。仅在授权和资源可用时显示原片链接、版权说明、视频和字幕；候选不转换成确认词条。
- **状态**：加载目录（保留卡位）／准备索引（不可显示假全量结果）／空目录（该快照无可展示条目）／筛选无结果（保留筛选，给出清除入口）／快照过期（显示上次时间）／数据版本不一致（给出刷新入口，不混用版本）／封面或播放不可用（卡片仍可检索，单条可重试）。展示「示例」与真实发布数据用不同标记，不混进真实排序。
- **无障碍**：主要操作支持键盘、明确可见焦点及读屏名称；筛选按钮用选中语义，分页使用当前页语义和禁用边界，结果条数经简短的 live region 通报。详情按对话框规则管理焦点与 Escape，不能丢失原触发点。文字至少 4.5:1 对比，非文本状态与焦点至少 3:1；触屏目标优先 44×44 CSS px。尊重系统主题及 reduced motion；不靠悬停、颜色或动画传达必要信息。

## 4. 静态目录契约与数据边界

复用 [动作迁移视频画像](<motion-profile.md>)、[画像 Schema](<../schemas/motion-video-profile.schema.json>) 和[中英受控词表](<../schemas/motion-tags.v1.json>)。**不要在浏览器读取或打包真实私有画像**，即使客户端只渲染其中一部分也不行。由离线导出器从已验证的数据做显式投影，另出版本化的 `motion-catalog/2` 契约；本设计不变更画像 Schema。

| 静态产物 | 字段或职责（设计） |
| --- | --- |
| `catalog-meta.json` | `schemaVersion`、`taxonomyVersion`、`rankingVersion`、UTC `asOf`、内容版本、快照模式（本地／公开／示例）、带哈希的目录路径、详情和词表路径规则。入口缓存需复核；内容块采用版本目录或内容指纹，防止混版。 |
| `home.<rev>.json` | 可选的首屏快速投影：同快照「成片混排／综合／第 1 页」的 24 条以内记录、准确总数和已排序 ID。暴露的字段仅为目录简表的子集，构建测试检查与全量计算一致；不是检索索引。 |
| `catalog.<rev>.json` | 一组作品简表和纳入的成片简表：不透明稳定 ID、关联键、可展示标题与说明、平台、画幅与时长、第一公开时间（本机模式为入库时间）、审核过的标签及显示名索引、海报的可发布引用和尺寸、热度值及数据状态、详情引用、成片验收状态和有来源的详情索引。列表简表应足以完成全库检索，不按页请求检索语料。 |
| `details/<id>.<rev>.json` | 选中作品/成片后加载。可含许可覆盖的播放地址、字幕、标签观察时间点或区间、确认/候选状态与简短限定、已公开的发布与授权说明；不能引用私有证据 ID、回执和原内部路径。 |
| `tags.<rev>.json` | 从词表与经确认的同义词表生成的可公开投影：英文稳定 ID、中文名、英文名、别名、分类维度、是否可公开。显示默认中文。已批准的平台原始标签用独立命名空间，不因同名而合并到分析词表。 |

**导出顺序**：验结构与媒体身份 → 核对记录/字段/资产发布许可 → 投影白名单字段 → 验证静态契约、引用与拟部署包 → 按同一内容版本生成索引和排名 → 等明确部署批准。公开模式缺授权即排除；本机模式只供本机/明确授权环境，不能给静态公网站点套一层「密码」就上传私有 JSON。现有两条原片、四份成片、相应截图和私有画像均不因此获得公开授权。授权未建立时，公开构建只用虚构夹具或显示空目录。更换、下架时出新快照并检查媒体宿主与缓存可见性；已被下载或缓存的副本无法保证召回。 本机查看用绑定回环地址的只读静态 HTTP，避免浏览器从 `file://` 加载 Worker 和 JSON 的限制；不假设公网托管能读取本机文件，不配置私有目录外发。

**禁止字段**：内部文件路径、真实画像全量、媒体文件哈希的私有索引、工作流和种子、下载日志、执行节点/队列编号、收据、作者私有信息、短期签名 URL、凭据及配置。即使初始化后从界面隐藏，也不进入任何静态文件或 sourcemap。标题/简介/标签当纯文本渲染；静态 URL 只接相对的生成资源或允许列表内审核过的 HTTPS 媒体与原站作品地址，不接受任意 HTML、嵌入脚本或 URL 协议。授权按正文、封面、视频、原音、字幕、平台标签/指标分别判定，原站可见不等于允许复制或热链。

## 5. 中文优先的全库模糊检索与 Tag 筛选

统一流程：`载入同一快照的目录简表 → Worker 建索引 → 文本召回 → 标签和结构筛选 → 排序 → 分页`。近似匹配、精确筛选和显示三者独立。

1. **字段及权重**：公开作品/成片标题 1.00，受控标签 ID、中英名、已审核别名 0.95，平台原始标签/话题 0.85，可发布简介和公开动作摘要 0.65，结构化详情 0.60，平台/角色/画幅等辅助描述 0.55，显式开启的观察／对照／限制说明 0.46。稳定 ID 和经批准的源 ID 可精确跳转。搜索原片、成片或全部时，控制分析标签和详情范围；标题及平台元数据始终标来源。只索引导出的详情字段，不导入提示词、文件路径、回执或未投影的私有全文。说明命中注明来源，不冒充已确认标签；候选观察说明需同时启用候选。
2. **归一与召回**：查询和索引统一 NFKC、小写、规范空白，标点视作边界；保留 ID 的原样精确匹配。中文按连续汉字做子串、单/二字候选索引；英文以词为单位，可跨中英文查明确别名，例如「手势舞」和 `gesture-led dance` 指向同一受控 ID。空格分隔多词默认 AND（每词在范围内有证据即可），引号内为连续短语，短语与一字查询不作模糊扩展。归一后无文字也无合法筛选则回全库。v1 不宣称自动拼音、任意繁简互换或语义同义；需要时以审核词典扩展。
3. **记分**：每个检索词在所有适用字段只取最高 `字段权重 × 匹配系数`；匹配系数精确值/词/整条别名 1.00、词前缀 0.92、连续子串 0.85、受限错别字 0.70（短语仅连续匹配，不跑错别字）。汉字词三字起、至多一处编辑；英文四字起，4–7 字至多一处、8 字及以上两处编辑。对满足阈值的候选用有界编辑距离二次判定，不能只用索引相似度放行。词项得分均值为相关度 `R∈[0,1]`；完整编号精确命中可置顶，但仍遵守筛选。输入上限 120 个 Unicode 字符、12 个检索词，超限提示。高亮用纯文本范围，新查询以序号废弃旧 Worker 响应。
4. **标签是精确筛选**：结构化参数命中稳定 ID，不把近似拼写自动算成选中标签。按中文/英文/别名筛到正确标签，再点选。标签选择默认同时满足（AND），平台和角色的多选在各自组内任选（OR），不同组同时满足。平台原始 tag 用 `native` 命名空间；`source`、`rendition` 区分原片/成片观察，支持同词分开筛；配置标签另列。`candidate` 和 `not_observed_in_samples` 都不计为确认标签；候选仅在显式启用且已获公开许可后进入候选结果。选了「BM01」并同时选多个成片标签时，必须由**同一份** BM01 成片满足，不能用 SA02 或另一尝试补齐。作品视图可显示命中版本和匹配字段，避免误读为所有版本都具备该动作。
5. **交互**：搜索输入约 150 ms 防抖，Enter 立即查询；URL 分享当前公开查询条件，例如 `#/videos?q=手势舞&tag=source%3Acontent.gesture_dance&variant=BM01&sort=trend&p=2`（浏览器编码 UTF‑8）。标签计数以尚未分页的筛选结果为基准，清楚注明选中条件；后端不存在所谓「搜索当前页」接口。重置筛选和无结果时同一逻辑回到第一页。

检索覆盖**全部已准公开并标记为可检索的文本**，不因卡片只显示两行而截断，也不依赖详情已加载。若长简介或公开摘要使简表超预算，将完整授权索引文本放到同版本检索分片，不把仅命中首批分片的页面标成完整结果。中文三字词中间错字可能没有相同二字片段；模糊召回用单字倒排等保真补充，再对长度有界的候选做编辑距离，搜索不到时不能仅凭没有二字片段就宣告无结果。原片与成片筛选先针对对应记录评估，作品聚合不跨成片拼合查询条件。

## 6. 热度与新鲜度排序：时间 55%，热度 45%

**热度口径**：v1 用已获准使用的来源平台互动快照，不是本站播放、不抓在线指标，也不是用户验收分。离线导出时每条来源只入一次热度样本，双版本共享来源热度，重跑不增加权重。跨平台不能直接比播放数。阈值、权重和时钟属 `rankingVersion`，改口径要重新导出并注明。

1. 选 `asOf` 以前最近一份合规互动快照，`asOf` 是目录生成固定 UTC 时间。至少需要有效播放量和统计时间；超过 30 天、缺失、越界或只有一项可比较来源时，标 `H = null`（分别显示「过期」「未采集/不可比」）。不能用今天发布日期、构建时刻或零补这种数据。实际提供的零仍是 0。
2. 有效快照中 `raw = ln(1 + 播放 + 4×点赞 + 6×评论 + 8×转发)`。只使用已采且允许比较的分量；按「平台 × 指标可用掩码」分组，避免把不支持转发的平台或缺项当零对比。同组按 `raw` 升序、并列取平均秩（从 0 起）：`P = rank/(n−1)`。小样本向中性收缩，`H = 0.5 + n/(n+8)×(P−0.5)`，`n≥2`。不把 `H` 和原始互动数混显示；取样时间与统计口径可查看，显示热度若无公开授权则设为未知。无组间校准，不把跨组热度当成同一平台的真实流行度。
3. **新鲜度**用该成片的首次上架时间（本机目录用首次入库），而不是采集、改标签或仓库提交时间；新发布的成片可提升对应作品卡。作品时间为本视图可见且满足成片筛选的最新成片时间；元数据已获准但无成片时取作品首次入库/上架时间。UTC 计算 `ageDays = (asOf − listedAt)/86,400,000`，`F = 2^(−ageDays/14)`。未来时间在导出阶段判为无效；缺时间令 `F=0` 并标未知，不补成今天。
4. **综合（首页默认）** `T = 0.55×F + 0.45×(H ?? 0.5)`。有搜索词且排序仍选综合时，先处理精确编号，再按 `0.75×R + 0.25×T`。**最新**按首上架时间降序（未知在后）；**最热**按 `H` 降序（未知在后）；二者只在已匹配集合内重排。分数按 10⁻⁶ 量化后比较，同分按时间降序，再按固定公开 ID 字典序升序，保证刷新与翻页不抖。热度分组不受搜索/当前页变化。页面显示「热度快照截至 …」，没有实时字样。

| 算例（虚构，H 指已经归一化后的热度） | 上架日龄 | H | 首页综合 T |
| --- | ---: | ---: | ---: |
| 稍旧、热度较高 | 5 天 | 0.83 | 0.8029 |
| 较新、热度中等 | 2 天 | 0.58 | 0.7591 |
| 新、热度未采集 | 1 天 | — | 0.7484（0.5 仅用于计算） |
| 较旧但很热 | 28 天 | 0.92 | 0.5515 |

v1 仍实现完整的综合、最新和最热排序。若整个快照无可比热度，综合自然退化为以时间为主的顺序，「最热」标「暂无可比较热度」，提供切回最新的入口。不显示假计数。维护者在有新的授权数据或互动快照时生成并审核新版本；浏览器不随客户端时间重算热度。上述权重是初版配置，不是已做用户实验的最优参数。

## 7. 工程结构、性能与静态部署

**实现栈**：Vite + TypeScript + React，用普通 CSS 自绘参考视觉，不引入重型 UI 套件。纯函数实现投影契约、排序、标签与字符串匹配；Web Worker 在浏览器内建索引和检索。代码位于 `web/catalog/`；`catalog/` 下按职责拆为读取与校验、索引/筛选、路由、工作台组件、播放器、主题样式/令牌、测试夹具。真实目录只在明确的数据发布步骤交给构建，不作为项目默认 public 目录或测试夹具。发布后是一份静态站点，不依赖 DeepSeek Harness 注入、API 服务、凭据或本机路径。

- **取数与缓存**：默认无条件首页可先用可信 `home` 投影显示首屏；搜索、过滤、其它模式／页码及直达链接按对应快照等待全库索引。首屏关键资源优先，完整索引在其后低优先级加载；准备好才给出完整检索结果。没有 `home` 时只能显示加载状态，不能拿局部索引冒充全量。详情和当前页之外的封面不请求；首排封面可优先，其余懒加载且预留宽高。索引可分片；失败则提示恢复，不混用不同版本。轻量存储仅保留主题及非敏感偏好；不把本机私有目录缓存进公共 PWA 或跨构建复用。用原生播放器及 `playsinline`、`preload=none`，不自动播放；关闭清理播放资源。仅用授权发布的 MP4（v1 优先 H.264/AAC）或兼容静态资源，验证 HTTPS、Content-Type、Range 和适用的 CORS。
- **性能目标（待实现实测）**：以 2,000 作品、4,000 成片的中英测试目录、Chrome 桌面 4× CPU 降速、1.6 Mbps/150 ms 网络为参考。默认空查询首屏 LCP ≤3 s；首屏关键路径压缩传输总量 ≤320 KiB（含入口、壳、首页投影与首排海报，JS ≤180 KiB gzip）。完整检索索引/词表初始测试预算 ≤600 KiB gzip，不让首页等待索引完整下载；冷启动另测完整索引可用时间（目标 ≤8 s），索引就绪后查询 p95 ≤150 ms（不含输入防抖），Worker 不阻塞输入。直达搜索链接的索引等待须明示。390 px 真机补测首屏、触屏、详情和失败恢复。超过合成测试预算先拆数据或压缩详情/海报，不裁掉授权索引字段、不改成只搜当页。

| 目标 | 构建与上线设计 |
| --- | --- |
| **GitHub Pages（首选）** | 当前 `npm run build:pages` 输出 `dist-pages`。项目站 `base='/Hottest-animation-clones/'`，独立域名则 `base='/'`；目录和媒体相对路径统一按部署 base 解析。路由用 Hash，列表与详情链接刷新不依赖服务器重写。[公开示例入口](https://copypasteltd.github.io/Hottest-animation-clones/)；[Pages 工作流](https://github.com/copypasteltd/Hottest-animation-clones/actions/workflows/pages.yml)只允许本仓库主分支手动运行，验证站点路径与产物后才上传，不随普通推送部署。Pages 当前官方发布站点上限 1 GB；不把它当批量视频分发仓。 |

## 8. 开发拆分与验收门槛

1. **静态数据与契约**：先写导出/校验及虚构夹具（两种画幅、两版本、历史尝试、缺封面、缺热度、候选比心、同名标签不同来源）。断言真实画像和媒体引用不会渗入公开构建，空目录可运行；不改原片、生成图或双版本运行契约。
2. **搜索与排序**：用同一输入快照在两种部署 base 得到相同结果。测试查询「手势舞」「gesture-led dance」「比心」及中文三字错别字、英文 typos，命中跨原分页的末尾记录；来源不同的同名标签不串、候选默认不计，多个成片标签必须同版本满足。验证最新/最热/综合、缺值、并列、时钟固定、重复与跨页不漏，检查综合虚构算例。
3. **视觉与交互**：照第 2 节校准标志性布局和浅深主题。测试窄屏、混合比例、Tab、Escape、回退恢复、筛选状态分享、播放器失败/切换、不自动播放及内容无横向溢出；无参考时不虚报视觉一致。
4. **发布门禁**：开发、公开某些标签/媒体、站点部署是三个单独授权点。之后只有明确确认平台、范围、可公开数据与宿主才执行部署；第三方媒体授权未清理不得先上线播放。当前交付前端源码、可构建的虚构示例与本机私有预览，另以手动工作流发布虚构示例，不公开真实数据或媒体。


本机版默认地址是 http://127.0.0.1:4176/。只播放已验证的迁移成片；原片显示归档资料及可指向的原站链接，不复制原片进预览包。点击「播放成片」才请求媒体，切版时卸载旧播放器。检索覆盖清洗标签、关键词和已投影详情；原片、成片和配置分来源。仅在启用「同时检索观察与复核说明」时匹配该类文字；候选观察还受候选开关约束。抽样未见不生成候选或确认标签。互动热度来自构建时已归档快照，更新目录时重算；不抓实时指标。稳定本机 ID 绑定源媒体与实际尝试，不充当将来的公开发布 ID。
