# 项目路径结构与开源维护规范

适用范围为 [v0.4 产品需求](12-项目需求梳理与实现方案总纲.md)和 [运行与交付规范](13-动作迁移运行与交付规范.md)。项目内路径以仓库根为基准，原片、运行记录和成片各有存放位置。

## 项目目录

```text
AI动作迁移库/
  README.md / README.zh-CN.md    双语项目入口
  AGENTS.md                     维护约束
  src/ scripts/ tests/ .github/  包版本、维护脚本、测试与 CI
  configs/
    project.example.toml        公开的无敏感信息配置样例
    project.local.toml          私有运行配置
  docs/
    README.md / en/             文档导航与英文说明
    12-*.md / 13-*.md / 14-*.md  现行产品需求、运行规范与验收
    15-*.md … 19-*.md            路径、人物、构图及发布规则
    templates/ schemas/ examples/  执行模板、结构与虚构记录
    evidence/                   历史试验的公开文字摘要
    images/characters/          精确授权的 8 张展示 PNG 与 manifest
    local/                      私有设备路径和本地配置说明
    archive/v0.3/               v0.4 之前的本地文档档案
    runs/<run_id>/               任务说明、提示词、视觉审核
  media/sources/<source_id>/     原片、来源侧车与探测摘要
  standard-assets/               正式人物、S02、构图与各自当前清单
  workflows/                     本地私有工作流副本与版本记录
  runs/<run_id>/                  机器记录、实际参数、远端回执与候选
  outputs/<run_id>/               通过审核的本地成片
  tooling/                        历史运行工具
  .local/                         私有维护配置与回执
```

既有实验媒体、运行记录与工具保留历史路径。现行工作流入口以指定 4090 的 ComfyUI 项目为准。本地 `workflows/` 用于保留经过检查的版本记录或副本。源素材、任务记录和实际输出按本项目目录保存。[运行与交付规范](13-动作迁移运行与交付规范.md#3-4090-工作流)

## 当前角色与构图文件

人物读取 `standard-assets/characters/current.json` 指向的 `selection.v2.json`，校验 SA02 正面基准与 BM01 正面基准和获批四视图。构图读取 `standard-assets/framing/current.json` 指向的 `s02-master-set.v2.json`，记录所选目标图的版本、哈希及审核状态。S02 空场独立版本化。历史 v1 文件用于追溯旧决定。[SA02](16-SA02二次元角色使用约束.md) · [S02 与目标图](17-S02场景定稿与四张构图母版规范.md) · [BM01](19-BM01真实角色替换与JK03退役约束.md)

公开克隆只有八张展示副本及清单。正式运行需要私有角色注册表与正式文件，缺少时角色锁报告具体缺失。[展示清单](images/characters/manifest.json)

## 本地检查与公开同步

```bash
python -m pip install -e ".[dev]"
python scripts/bootstrap_workspace.py
python scripts/check_project_docs.py
python scripts/check_release.py
python -m unittest discover -s tests -v
python scripts/check_repository.py
```

初始化只创建工作区目录。文档检查验证 5 项需求、10 个计划验收用例、公开链接和虚构运行记录的结构。发布及索引检查核对双语 README、八张 PNG 的身份与公开路径。现有维护命令以离线方式执行。实际下载、路由和模型效果以真实样片检查为准。[实施与验收](14-实施计划与验收矩阵.md)

Git 跟踪发布清单内的原创规格、维护工具、虚构样例和八张授权的展示图。源片及侧车、生产成片、私有注册表、工作流实作、历史档案、模型、设备配置和凭据留在本地。明确暂存已审核文件，按用户指定仓库正常同步并核验远端提交。前端或预览服务需要用户明确给出开发范围。[发布规则](18-开源发布与持续同步规范.md) · [维护约束](../AGENTS.md)
