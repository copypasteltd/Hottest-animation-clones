# 产品需求 · 链接到基准白模视频

需求基线 v0.4。用户提供 Bilibili、X 或抖音作品链接，项目交付基准人物在 S02 白色场景中复现源动作的成片。常规任务只需作品链接，角色预设和工作流由项目配置。当前实现和实测范围集中记录在进度页。[当前进度](<status.md>)

## 五步需求

| 需求 | 项目负责 | 完成证据 |
| --- | --- | --- |
| R-01 | 通过 `/ra-video-download` 下载指定作品或链接选中的分段。 | 每条链接对应经过媒体核验的原片与来源记录，或可定位的下载结果与原因。 |
| R-02 | 回看表演区间，分别决定半身／全身与单人／多人，并识别适用姿态。 | 记录实际可见部位、参与者、关键动作、证据时间点与目标取景。 |
| R-03 | 按项目角色预设、姿态、取景和表演人数，匹配 S02 的目标替换图。 | 记录选用的目标图版本、哈希及表演者对应关系。 |
| R-04 | 使用指定 RTX 4090 的 ComfyUI 现有 H3 工作流完成角色和场景替换。 | 实际工作流、活动分支、输入映射、任务回执和对应结果均可追溯。 |
| R-05 | 取回视频并复核人物、场景、构图、动作和节奏，交付审核通过的基准白模 MP4。 | 成片有项目内路径、媒体摘要、审核结论和动作范围。待审或失败项附原因。 |

## 用户输入与项目预设

- 接收一条或多条作品链接。每条输入都有结果，批次中已具备条件的条目可独立推进。
- 项目设置阶段确定常用人物、场景及适用工作流。日常执行沿用匹配配置。来源无法定位、动作证据不足或找不到匹配路线时，报告具体条目和所需信息。
- 以完整连续表演为默认处理范围。人物、动作或镜头发生变化，或工作流时长有约束时，记录实际处理区间和未覆盖部分。
- 半身用于以上身和双手为主的动作。全身覆盖关键脚步、接地、转身或位移。站立是当前资产覆盖的姿态，坐姿和其他姿态可按相同方式增加预设。
- S02 使用纯白背景与细浅灰地面网格。人物、场景、取景和多人对应在任务中各有明确配置。[S02 与目标图](<../assets/reference-images.md>)

## 交付范围

每个执行条目交付已通过审核的基准白模视频和简要结果。批次汇总列明完成项、可用动作范围、待核原因及失败项。保留原片、实际处理区间、选图、工作流版本与审核证据，便于追查问题或续接原任务。[运行记录](<../operations/run-record.md>)
