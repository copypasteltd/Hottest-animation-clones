# SA02 二次元角色使用约束

SA02 是已选定的栗发二次元亚斯娜。正面根图已批准，保留同一面孔、发型、红白骑士服和 2D 动画画风。[当前 S02 构图](17-S02场景定稿与四张构图母版规范.md) · [展示清单](images/characters/manifest.json)

## 1. 正式参考

当前角色清单通过 `standard-assets/characters/current.json` 指向 `selection.v2.json`。SA02 的固定角色引用为 `char-asuna-sa02@1`，正式根图与 asset 记录位于 `standard-assets/characters/char-asuna-sa02/v1/`。

| 文件 | SHA256 与状态 |
| --- | --- |
| 正面全身根图 | `dd876e86f8602b60d16f115a080058669e95a5c6fbf440c8bac7c870dc505659`，已批准。 |
| 正面、侧面、背面和脸部四视图 | `953e12f5cf30f0fa2ededbb813f600938cbe8686365759550e5fe0b5607a9fd0`，待确认的辅助候选。 |

四视图候选在独立 supporting-views 路径中保留，正式运行仍以正面根图和当前构图清单为依据。角色锁通过后，按实际动作范围选择 F01 膝部中景或 F02 全身。运行用图以正式文件和当前清单的校验结果为准。

## 2. 外观约束

| 维度 | 需保持 |
| --- | --- |
| 媒介 | 日本 2D 动画线稿与赛璐璐上色。 |
| 五官与头发 | 锚点里的眼型、棕色眼睛、脸部轮廓、栗色长发和侧编发。 |
| 服装 | 红白高领骑士服、分层裙摆、白色不透腿部打底与红白靴。 |
| 双手与道具 | 空手表演，手指在动作所需范围内清楚可查。 |
| 场景 | S02 白背景与细浅灰地面网格，按 F01／F02 构图核验。 |

同源动作在人物、画风、手势和构图上分别审核。若更换角色外观或正式参考，按新版本登记并取得用户批准。公开展示副本的范围按[发布规范](18-开源发布与持续同步规范.md)执行。
