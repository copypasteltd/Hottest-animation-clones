# 动作迁移实施与验收

基线 v0.4。验收对象是从一条作品链接得到经检查的基准白模动作迁移视频。现有离线检查验证文档、结构示例和本地文件身份。下列实际下载、工作流接线、生成和视觉检查均按现场执行记录给出结论。[产品需求](12-项目需求梳理与实现方案总纲.md) · [运行规范](13-动作迁移运行与交付规范.md)

## 1. 实施顺序

1. **下载接入。** 用获准作品验证 `/ra-video-download` 的三站入口、原片落点、媒体探测和逐项报告。首条完整闭环可使用任一已验证站点，其余两站按各自结果标记支持状态。
2. **判断与选图。** 用单人手势、单人足部动作和共同表演的片段判断半身／全身及单人／多人，现场记录当前对应目标图。项目角色预设配置一次，常规运行直接沿用。
3. **指定工作流接线。** 核对 4090 指定目录的文件、活动分支、实际输入图与输出版式。先跑通一条素材与目标均已匹配的路线，再逐项验证单人半身、单人全身、多人半身和多人全身。工作流可按证据复用。坐姿等预设按实际需求增设。
4. **取回与审核。** 记录按原任务 ID 找到的结果，查媒体完整性，逐项看关键动作和场景，成片按私有本地路径交付。每个模型和路线只宣告实际检查过的范围。

## 2. 计划用例

| 用例 | 需求 | 测试输入与预期证据 |
| --- | --- | --- |
| TC-01 | R-01 | 从 Bilibili、X 和抖音各取一条获准作品链接。各站样片完成下载与媒体核验后登记该站通过，附作品与媒体身份、下载方式、原片及探测摘要。用 Bilibili 多 P 作品验证链接所选分 P。 |
| TC-02 | R-01 | 输入重复链接、访问受限链接和明确失败来源。逐条有结果，已有原片与回执仍可核对。 |
| TC-03 | R-02 | 单人腰上手势与单人全身步法各一条。半身和全身决定能定位关键事件，记录实际可见范围。 |
| TC-04 | R-02 | 双人共同表演、路人偶然入镜，以及切镜或关键部位被遮挡的样片。共同表演的各主体和相对关系皆被记录，证据不足区间给出复核结果。 |
| TC-05 | R-02, R-03 | 对单人和多人分别验证半身、全身选图，核对 S02、角色、姿态预设、人数对应与版本。缺匹配多人图时记录待补对象。 |
| TC-06 | R-03, R-04 | 核对指定目录中的真实图、活动分支与输入位。单目标图用已有 S02 组合图验证。不同参考图数量和多人映射以实际连接和输出检查记录为准。 |
| TC-07 | R-04 | 通过指定 4090 既有工作流提交一次，保存真实回执和对应输出。遇到状态未知时按原任务 ID 或已有提交记录核对。 |
| TC-08 | R-04, R-05 | 取回实际 MP4，验证非空、可解码和音视频属性，并确认属于原提交。损坏或缺失输出需有明确状态。 |
| TC-09 | R-05 | 对合格媒体在原动作关键时刻复核要求范围内的动作、顺序、节奏、身份、构图与 S02。需要多人或足部时验证对应与出框。出片失真给出缺陷区间，审核通过后交付成品。 |
| TC-10 | R-01, R-02, R-03, R-04, R-05 | 单次仅给作品链接，从已配置路线生成并取回可播放成片。执行记录能按源 ID、目标图、工作流与回执定位视频，交付材料使用私有本地输出路径。 |

## 3. 成片判定

| 维度 | 核验方法 |
| --- | --- |
| 文件 | 实际取回的文件非空且可解码，路径、尺寸、时长、流信息、哈希可核对。 |
| 人物 | 目标角色、画风及服装与参考相符。多人可辨认各目标及对应关系。 |
| 动作 | 核对必需手势、脚步或互动，检查事件顺序和与源动作的节奏。时间尺度由本次素材和预设确定。 |
| 场景与构图 | 核对 S02 纯白背景和目标构图应出现的细浅灰地面网格。关键时段所需的头、手、脚或多人站位均可检查。 |
| 音轨 | 检查实际音轨、是否保留原音以及与画面同步状况。静音按任务交付约定陈述。 |

验收记录使用样片名、相关区间、实际配置、发生时间、媒体和观察结论。已通过路线只覆盖核实过的人物／姿态／取景／人数和工作流版本。当前项目保留的约 13 秒 H3 样片是历史整段迁移证据，发现过手型、时序和足部出框偏差。当前 S02 单人和多人组合仍需按上表验证。[H3 历史摘要](evidence/H3基础用例公开摘要.md) · [记录模板](templates/动作迁移任务与交付模板.md)
