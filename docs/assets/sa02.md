## 外观约束

- 保持日本 2D 动画线稿和赛璐璐上色，以锚点里的棕色眼睛、脸型和栗色长发侧编发为准。
- 保持红白高领骑士服、红边与银色细节、分层裙摆、白色不透腿部打底和红白靴。
- 常规站立母版采用空手构图，保留手指和服装轮廓。直接参与动作的道具使用对应目标图和工作流。见 [动作道具](<reference-images.md#action-props>)。脸、发型、服装或媒介的改变需要登记新版本并取得确认。

角色版本和动作适用范围随实际运行记录追溯。公开展示按发布清单执行。[发布规范](<../maintenance/publication.md#display-assets>)
