# 公开页面演示媒体 / Public documentation media

本目录仅保存项目原创合成演示页面的真实浏览器截图及录屏派生文件，不包含真实舞者、角色图、模型输出、设备日志或凭据。

This directory contains real browser captures of the original synthetic documentation demo. It contains no real dancer, private character image, model output, device log or credentials.

截图和录像用于说明交互与设计思路，不证明骨架提取或动作迁移已实现。录制原始文件保留本地，公开MP4/GIF仅裁去等待/空白段并转换格式，具体范围和hash记在capture-manifest.json中。图像不得画成“截图”冒充录制。

Captures explain interaction and data boundaries, not inference quality. The original recording is retained locally; public MP4/GIF files are temporal excerpts and format conversions. See capture-manifest.json for provenance and checks.
